# Study configuration

- [generation/](generation/README.md): definitive source inputs, pair roster, prompts, scaffolds, model pins and generation settings.
- [annotation/talktag.json](annotation/talktag.json): TalkTag source pin and options.
- [segmentation/batchalign.json](segmentation/batchalign.json): generated utterance-boundary runtime and model pins.
- [validation/chatter.json](validation/chatter.json): native CHAT validator, checksums and required options.
- [evaluation/](evaluation/README.md): explicit framework inputs and classifier/metric protocol.
- [analysis/](analysis/README.md): explicit linguistic feature inputs and canonical ENNI metadata checks.

Use the single roster and exemplar CSV named in generation/experiment.json. Input changes require a fresh run directory and new recorded hashes. Scientific feature/text outputs remain pending until generated by the corresponding processing step.
